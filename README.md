# aria-kala-site-sync

سرویس ویندوزی برای همگام‌سازی تغییرات کالاهای نرم‌افزار آریا با وب‌سایت از طریق API.

## عملکرد

- اطلاعات اتصال به SQL Server را از فایل `Settings.ini` کنار فایل اجرایی می‌خواند.
- نشانی API و مشخصات احراز هویت API را از جدول `setting` پایگاه‌داده می‌خواند.
- با اجرای رویهٔ ذخیره‌شدهٔ `sp_kalachanged`، رکوردهای در صف ارسال را دریافت می‌کند.
- برای احراز هویت به مسیر `api/v1/authenticate` درخواست می‌فرستد و سپس اطلاعات کالا را به `api/v1/login` ارسال می‌کند.
- نتیجهٔ ارسال را در جدول `KalaChanged` ثبت می‌کند. رکوردهای ناموفق ارسال‌نشده باقی می‌مانند تا در چرخه‌های بعدی دوباره تلاش شوند.
- خطاها و رویدادهای سرویس را در پوشهٔ `Logs` کنار فایل اجرایی می‌نویسد.

## پیش‌نیازها

- ویندوز و .NET Framework 4.6
- SQL Server و دسترسی شبکه از سرویس به پایگاه‌داده
- دسترسی شبکه به API وب‌سایت
- Visual Studio یا MSBuild سازگار با پروژه‌های .NET Framework برای ساخت

## تنظیمات

### اتصال SQL Server

فایل `Settings.ini` باید در پوشهٔ فایل اجرایی قرار داشته باشد. سرویس مقادیر زیر را از بخش `[Form]` می‌خواند:

| کلید | کاربرد |
| --- | --- |
| `Server` | نام یا نشانی سرور SQL Server |
| `dataBase` | نام پایگاه‌داده |
| `user` | نام کاربری SQL Server |
| `pass` | رمز SQL Server |
| `LockNumber1` | مقدار خوانده‌شده از تنظیمات محلی برنامه |

نمونهٔ ساختار فایل (مقادیر را با تنظیمات محیط خود جایگزین کنید):

```ini
[Form]
Server=YOUR_SQL_SERVER
dataBase=YOUR_DATABASE
user=YOUR_SQL_USER
pass=YOUR_SQL_PASSWORD
LockNumber1=
```

### تنظیمات API

سرویس این مقادیر را از جدول `setting` می‌خواند:

| `tag` | `key` | کاربرد |
| --- | --- | --- |
| `sitesyncer` | `Url` | نشانی پایهٔ API |
| `sitesyncer` | `User` | شماره موبایل/نام کاربری API |
| `sitesyncer` | `Password` | کلید API |

## ساخت و نصب سرویس

1. فایل `SiteSyncerAria_DrDoosti.sln` را در Visual Studio باز و پیکربندی `Release` را بسازید.
2. خروجی و فایل `Settings.ini` را در یک پوشهٔ استقرار قرار دهید.
3. با دسترسی Administrator سرویس را با ابزار `InstallUtil.exe` مربوط به .NET Framework نصب کنید:

   ```powershell
   InstallUtil.exe .\SiteSyncerAria_DrDoosti.exe
   ```

4. سرویس را از Services ویندوز یا با دستور زیر اجرا کنید:

   ```powershell
   Start-Service SiteSyncerKalaAria
   ```

سرویس با حساب `LocalSystem` نصب می‌شود. در صورت نیاز به دسترسی شبکه‌ای خاص، حساب سرویس و مجوزهای SQL را در محیط استقرار بررسی کنید.

## پایگاه‌داده و صف ارسال

این مخزن شامل تعریف جدول‌ها یا بدنهٔ رویهٔ `sp_kalachanged` نیست. پیش از راه‌اندازی، پایگاه‌داده باید از قبل شامل جدول‌ها و رویهٔ مورد انتظار برنامه باشد. رویهٔ `sp_kalachanged` با پارامتر `@state = 0` فراخوانی می‌شود. وضعیت ارسال هر رکورد در `KalaChanged.SentToSite` ذخیره می‌شود؛ ارسال ناموفق برای تلاش مجدد در چرخه‌های بعدی باقی می‌ماند.

## ثبت رویدادها

فایل‌های گزارش روزانه در مسیر زیر ساخته می‌شوند:

```text
<پوشه فایل اجرایی>\Logs\
```

برای ثبت گزارش‌ها، حسابی که سرویس با آن اجرا می‌شود باید امکان نوشتن در پوشهٔ نصب را داشته باشد.
